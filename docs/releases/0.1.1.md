## User-visible fix

Normal finalization refuses incomplete coverage before writing immutable reports. Completed results can finalize the same unsealed run later. Intentional terminal-failure reports require a nonempty `--incomplete-reason` and remain incomplete/undetermined. Existing sealed reports remain immutable.

Update the installed skill with the same harness and scope, for example `npx --yes openspec-goldfish@0.1.1 --harness devin --local`, then start a new harness session. An earlier sealed incomplete run requires another explicit review invocation.
